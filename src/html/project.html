Cours : FTP

  • Compétences acquises

  • Installation et administration d'un serveur FTP sécurisé avec FileZilla Server.

  • Gestion des droits d'accès (lecture, écriture, suppression) sur les dossiers partagés.

  • Utilisation de groupes pour simplifier l'administration.

À travers ce TP, nous avons vu comment mettre en place un serveur et des clients FTP.

Nous avons vu comment mettre en place les permissions sur les différents dossiers partagés.

Cours : AD / WS

  • Compétences acquises

  • Création d'utilisateurs et groupes sur Active Directory.

  • Gestion des stratégies de groupes (GPO) pour empêcher l'exécution d'applications, gérer l'installation automatique de logiciels et gérer les permissions et accès.

  • Mise en place du lien entre l'AD et le DNS/DHCP pour la transmission du controlleur de domaine.

Ce TP a pour objectif de maîtriser la mise en place et le fonctionnement d'Active Directory, sur une machine virtuelle Windows Server 2019.

Nous avons mis en place un Active Directory avec des utilisateurs, groupes et GPO.

Nous avons également mis en place, sur le même serveur que l'AD, un DHCP, DNS et du routage logicielle.

Cours : Docker

Ce TP a pour objectif de découvrir l'environnement Docker via CLI (Command-line interface).

Nous avons vu comment confectionner une image et un conteneur via un fichier Dockerfile en gérant un volume et un réseau customisé.

Nous avons également mis en place docker-compose pour créer et gérer plusieurs images / conteneurs en même temps.

Enfin, nous avons crée un compte Docker Hub, pour publier notre image en ligne.

Projet : WebGL

Ce projet personnel a été réalisé dans le but d'apprendre à utiliser l'API graphique WebGL.

Projet : GCL

Ce projet personnel a pour but de créer un visualiseur d'aléatoire basé sur les nombres générés par un Générateur à congruence linéaire (LCG).

En effet, cet algorithme est très connu dans la génération de nombres pseudo-aléatoires et était présent dans certaines versions de PHP.

Malheureusement, celui-ci n'est pas considéré comme sécurisé cryptographiquement, étant donné qu'une de ses variables utilise la génération précédente.
